📌 Resumo

Este material reúne os principais cenários relacionados aos erros de Terminal Não Autorizado ou Cadastrado, incluindo problemas de OS vencida, CPF inválido, equipamento incorreto, terminal associado a outro estabelecimento, erros de comunicação e falhas de ativação.

Erro 12

Tópico: Problemas de Software

Sintoma: Token incorreto + Problemas de Comunicação

Solução: Realizar estímulo no cadastro, reset Dataware no TMS, provisionamento Salesforce, testar outro meio de comunicação, provisionar novo número de série e reiniciar o equipamento.

Erro 28

Tópico: Problemas de Software

Sintoma: Data e hora incorretos na máquina.

Solução: Orientar técnico ou cliente a corrigir a data e hora do equipamento.

Erro 29

Tópico: Problemas de Hardware

Sintoma: Tecnologia GPRS/WIFI descontinuada.

Solução: Solicitar substituição do equipamento ou encaminhar para retenção.

Erro 31

Tópico: Terminal Não Autorizado

Sintoma: POS associado a outro estabelecimento ou nunca cadastrada.

Solução: Reagendar OS ou efetuar reset de fábrica quando aplicável.

Erro 32

Tópico: Terminal Não Autorizado ou Cadastrado

Sintoma: Informação digitada incorretamente pelo técnico.

Solução: Validar CPF, CNPJ, ticket e informações inseridas durante a ativação.

Erro 35

Tópico: Autorização

Sintoma: OS vencida.

Solução: Liberar Ticket para continuidade da instalação.

Erro 41

Tópico: Problemas de Software

Sintoma: Existe OS de manutenção e desinstalação para mesma POS.

Solução: Cancelar a OS incorreta, validar desinstalação pendente e seguir orientação do processo.

Erro 43

Tópico: Problemas de Software

Sintoma: CPF do técnico inválido.

Solução: Confirmar CPF informado. Caso esteja correto, orientar técnico a procurar sua base.

Erro 44

Tópico: Problemas de Hardware

Sintoma: POS não corresponde ao projeto.

Solução: Reagendar OS e orientar o técnico a substituir o equipamento.

Erro 824

Tópico: Problemas de Comunicação

Sintoma: Falha de comunicação durante instalação.

Solução: Reset Dataware, estímulo cadastro, provisionamento Salesforce, testar Wi‑Fi/Dados móveis e reiniciar equipamento.

Erro 837

Tópico: Problemas de Comunicação

Sintoma: Problemas de comunicação.

Solução: Aplicar os mesmos procedimentos do erro 824.

Erro E2

Tópico: Problemas de Hardware

Sintoma: Tecnologia GPRS/WIFI descontinuada.

Solução: Solicitar equipamento atualizado ou transferir para retenção.
